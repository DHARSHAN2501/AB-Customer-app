# Smart Restaurant - Customer App 🍽️

The customer-facing digital ordering application for **Arunachala Bhavan**.

## Features
- 📱 Interactive QR digital menu with category filtering and dish search
- 🛒 Cart management with special instructions per item
- 🚚 Dine-in table ordering & Home Delivery bulk orders (>25 items)
- ⏱️ Real-time order progress timeline tracking
- 🔔 Direct table bill request button
- 🚫 Safe cancellation handling with direct restaurant contact support

## Setup & Running
1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure environment:
   ```bash
   copy .env.example .env
   ```
   Add your Supabase URL and Anon Key.
3. Start development server (Port 3000):
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
